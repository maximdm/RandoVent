## Creating a New ADR

1. Copy `template.md` to `NNNN-title-with-dashes.md`.
2. Fill in Context / Decision / Consequences, and set the Status.
3. Add a row to the index above.

Statuses: Proposed → Accepted → Deprecated → Superseded (or Rejected).
